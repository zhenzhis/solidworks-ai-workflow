# 机械建模工作约定

- 保持流程简单：明确需求 → 复用模板或短作业脚本 → SolidWorks 执行 → 实际核验 → 交付。默认服务参数化零件、小型装配与关联工程图。
- 统一使用 `<UPSTREAM_ROOT>` 中的技能与脚本；Python 为 `<PYTHON>`。按需读取根技能及圆角、螺纹、工程图等子技能，能力边界以 `capabilities.yaml` 为准。
- 本项目 `.codex/config.toml` 配置 `solidworks` 执行 MCP 和 `swapi-pilot` 文档 MCP。完整零件可直接复用同一技能库执行短脚本；同一 SolidWorks 会话串行写入，操作前确认目标文档和配置。
- 默认模板已指向本机随附的毫米 MBD 零件/小型装配模板及 `gb.drwdot`；具体任务仍须核对单位、图幅和投影法。CLI 配置检查应使用桌面端当前附带版本；PATH 中旧版 `codex-cli 0.144.0` 不支持现有全局配置，不能据其报错修改全局设置。
- 未封装 API 先查 `swapi-pilot` 或官方文档；按本机版本核对接口。官方本地帮助位于 `<SOLIDWORKS_INSTALL>\api`。文档查询仅发送 API 名称和必要的通用问题。
- 明确单位、基准、孔的用途及关键尺寸；SolidWorks API 使用米、弧度。常用尺寸应可命名修改，约束表达设计意图；只有缺失信息实质影响结果且无法安全推断时才询问。
- 修改已有模型时遵守用户授权，保留无关文档和未保存内容。新建任务默认在 `sw` 下按任务保存，复用现有资料，不自动升级技能或增加执行框架。
- 关键尺寸和孔位从实际尺寸对象或 B-Rep 回读；`GetPartBox` 只作外形概览。按任务检查重建、实体、孔槽、配合和导出结果，实际查看预览；参数化交付还需验证代表性改型及保存重开。
- 工程图检查真实尺寸实体、孔槽定位、必要视图和 PDF 可读性；记录实际验证范围，不能将自动审查分数当作全部设计要求已通过。
- Jev 暂不接入默认流程；优先模板复用和确定性代码。AutoCAD、C# Add-in、其他 MCP 或高级仿真仅在实际任务需要时扩展。
